So einfach geht das


Du brauchst keine Zeile Code zu schreiben. Die Idee ist deine, den Rest macht der Agent.



  
Idee
Ein Alpental? Eine Unterwasserstadt? Ein Wüstenmarkt mit Karawanen? Sag in zwei Sätzen, was es geben soll.

  
Auftrag
Fülle unten den Generator aus und kopiere den fertigen Auftragstext in deinen Agenten (z. B. Claude Code).

  
Bauen lassen
Der Agent liest nur die Anleitung und die Vorlage, baut die Welt und prüft sie selbst, bis die Abnahme „BESTANDEN“ meldet.

  
Verbinden
Eine Zeile in worlds/index.js genügt: Auf dem Stadtplatz erscheint ein neues Tor zu deiner Welt.





Warum das so reibungslos klappt



  
Kleiner Vertrag
Eine Welt ist ein Ordner und ein Aufruf: weltRegister({ … }). Der Agent muss das übrige Spiel (über 11 000 Zeilen) nicht lesen.

  
Mehrere Agenten gleichzeitig
Jede Welt hat ihren eigenen Ordner und eine eigene Zeile im Verzeichnis. Zehn Agenten können parallel bauen, ohne sich in die Quere zu kommen.

  
Schnell geladen
Eine Welt wird erst beim ersten Durchgang durchs Tor geladen. Der Start von Neu-Zürich wird dadurch nicht langsamer.

  
Gleich Spielgefühl
Figur, Drache, Rakete, Fallschirm, Tag und Nacht, Pflanzen und Töne funktionieren in jeder Welt, ohne dass der Agent etwas dafür tut.

  
Eingebaute Abnahme
Ein Prüfskript testet Vertrag, Bauzeit, Draw-Calls, Gehen in 8 Richtungen und das Rücktor. Fertig ist die Welt erst bei „BESTANDEN“.

  
Dein Stil
Low-Poly wie die Hauptwelt oder ganz anders: Thema, Farben, Grösse und Stimmung bestimmst du im Auftrag.

Dein erstes Tor in 5 Minuten



  

    
Lokal starten, im Ordner des Repositorys:

    
python3 -m http.server 8765
# Browser: http://localhost:8765/games/weltsimulator/

    
Neue Welt prüfen, im Ordner games/weltsimulator:

    
node tools/play-test.cjs tools/welt-check.js --welt alpental

    
Bei „BESTANDEN“ ist die Welt fertig. Im Spiel auf den Stadtplatz laufen und durch das neue Tor gehen.

  






  
Jede Welt, die du baust, macht das Spiel grösser. Fang mit der ersten Idee an. ✨
